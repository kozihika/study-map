  1. 欠損値処理
  2. 必要に応じて 外れ値の除外 / 特徴量の絞り込み / 標準化 / 特徴量の追加
  3. 特徴量xと正解tに分割

ポイント

  3. OK → 最終性能評価

ポイント

欠損値（NaN）があるとモデルは学習できない。消すか、何かで埋める。

コード

# 列ごとの欠損値の数
df.isnull().sum()

# ① 行削除
df2 = df.dropna()

# ② 全体の代表値（平均値）で埋める
df['age'] = df['age'].fillna(df['age'].mean())

# ③ グループごとの代表値で埋める
group_mean = df.groupby('pclass')['age'].transform('mean')
df['age'] = df['age'].fillna(group_mean)
