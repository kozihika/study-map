# 教師あり学習マップ

教師あり学習の全体像（鳥の目）から、各トピックのコード（虫の目）へ潜れる学習ページ。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 全体像の図と、各トピックの詳細（`<article>`） |
| `style.css` | 見た目 |
| `script.js` | 箱をタップしたときに詳細をポップアップ表示する |

## 詳細の書き足し方

`index.html` の下の方にある「虫の目」セクションで、該当する `<article>` の中を編集する。
コードの中に `<` `>` `&` を書くときは `&lt;` `&gt;` `&amp;` に置き換える。
